# Orange scripts

These scripts built the v2 upper legs, the standing assembly and the walk animation. They were moved here from a temporary session folder so they survive.

**Requirements**
- Python packages: `pip install numpy trimesh scipy shapely manifold3d rtree pillow`
- Fusion scripts (marked "Fusion" below) run inside Fusion through the Fusion MCP. Each one starts with `def run(context): pass`, then loads the file with `exec(open(path).read(), g)`. Units inside Fusion are cm.

## walk/: walking animation

| File | Runs in | What it does |
|---|---|---|
| `gait2.py` | Python | **The smooth walk.** Goes Rest → Stand → 3 step cycles → Stand → Rest, using the same diagonal pairs as Sesame (R1+L2, then R2+L1). Hips swing ±`HIP_AMP` (20°) around the Stand angles, and knees lift `KNEE_LIFT` (35°). Clash-checks every frame and writes `gait_frames.json` / `gait_report.json`. Change `HIP_AMP`, `KNEE_LIFT`, `CYCLES` or `PER_CYCLE` at the top to tune it. |
| `gait.py` | Python | Replays Sesame's original `runWalkPose` (firmware/movement-sequences.h). It also holds the shared geometry code (leg meshes, hip and knee axes, collision check) that `gait2.py` reuses. |
| `capture.py` | Fusion | Moves the legs frame by frame in the open `Orange_Assembly_v2_WithLegs` and saves one PNG per frame. Call `capture(start, end, outdir, keep_camera=True)` to keep your own camera angle. Do about 50 frames per call, because longer runs time out. |
| `gait_frames.json` | data | Per frame: the 8 servo angles and the transform for each moving part. |

**Angle mapping (same as Sesame's angle diagram):**
- **Hips:** 90 = leg straight out sideways. Stand = R1 135, R2 45, L1 45, L2 135.
- **Knees:** 0 or 180 = lower leg straight down (R4/L3 = 0, R3/L4 = 180), and 90 = horizontal. A knee lift always swings the foot outward.

## assembly/: standing robot

| File | Runs in | What it does |
|---|---|---|
| `poses.py` | Python | Places every part of the standing robot and writes `poses.json`. |
| `build_asm.py` | Fusion | Builds the assembly from the v2 STEP files, `poses.json` and the widened base `base_wide.step`. |
| `asm/` | data | Every assembly part as STL, with its Fusion placement in `info.json`. The walk scripts read these. |
| `tunnels.json` | data | The 4 servo-plug tunnel boxes of the base (9.6 × 4.8 at 63°). |

**Leg placement used in `poses.py`:**
- **Corners:** "1" legs at the rear (switch end), "2" legs at the front (display end). L legs on −Y, R legs on +Y.
- **Hip servos:** heads up, at the outer end of each bracket. Hip shafts at X −28.98 / 80.40, Y −34.78 / +30.02 (base widened 1.5 mm per side).
- **Upper legs:** the multi-hole plate pocket sits on the hip servo, and the labelled plate pocket takes the lower leg's servo.
- **Lower legs:** L4 and R3 are turned over so every shield faces outward.

## upper_leg/: upper leg designs

| File | Runs in | What it does |
|---|---|---|
| `organic.py` | Fusion | Builds an organic (Bone) upper leg. Set `STYLE` to `bone`, `sinew` or `cells` (SingleHole / TwoHoles / MultiHole). Generated by `assemble.py` from `organic_mid.py` + `build_concept_final.py` + `cells.json`. |
| `build_concept_final.py` | Fusion | The tactical concept builder. Set `WIN` for the windows; the triangle-window version used two triangles. |
| `label.py`, `export_all.py` | Fusion | Engrave L1/L2/R1/R2 and export the four variants per design. L2 and R1 are L1 mirrored in z. |
| `verify_all.py`, `checks/` | Python | Check exported legs against the original L1: watertight, horn pockets, screw holes, label render. |

## bottom_cover/: removable bottom cover

| File | Runs in | What it does |
|---|---|---|
| `cover.py` | Fusion | `build()` makes the cover in a new design, with the rear tongue, front square-hook latch, optional screw holes, rocking bevel and outer chamfer. It also cuts the 2 mm inlay slots and creates the 6 matching cosmetic inlay bodies (`Inlay_*`, 0.15 mm clearance). Change `T` (plate thickness), `DEPTH`/`CLR` (slot depth / inlay clearance), or the latch dimensions at the top. |
| `cover_skirt.py` | Fusion | The extra skirt cover (`Orange_BottomCover_Skirt_v2`): same builder with `WALL` 2.22 (flush with the body sides) and the side skirts (`SKIRT_X`, `SKIRT_TOP`). Its own chamfered panel was replaced by the armour plates from `skirt_patterns.py`. |
| `skirt_patterns.py` | Fusion | The 3 skirt face patterns that were compared (A shell echo, B armour plates, C panel line + bolts). `build_variant('B')` cuts the chosen one into both skirts. |
| `check_skirt.py` | Python | Gap checks for the skirt cover: base, hip servos and every walk frame. |

The base needs the matching pockets, which are already in the saved Fusion base as features `CoverTongueSlot (1)` and `CoverLatchPocket (1)`:
- **Rear slot:** x −35 face, y −9.38..4.62, z −2.7..−1.0, 1.5 deep.
- **Front pocket:** x 88.6 face, y −8.38..3.62, z 4.2..5.8, 1.4 deep.
